# 🎵 Chat de Música en Python

## Descripción del proyecto

Este proyecto consiste en desarrollar un chatbot de música utilizando el lenguaje de programación Python. Su función principal es interactuar con el usuario mediante mensajes de texto y responder preguntas relacionadas con la música.

El chatbot puede mantener una conversación sencilla, reconocer algunos mensajes del usuario y proporcionar respuestas relacionadas con sus gustos musicales. El objetivo es practicar la programación en Python y aprender cómo funciona un sistema de conversación automatizado.

##  Objetivo

Crear un chatbot que permita al usuario conversar sobre música de manera sencilla, utilizando estructuras de control, funciones, clases y manejo de texto en Python.

## Tecnologías utilizadas

- **Python:** lenguaje utilizado para desarrollar el chatbot.
- **Visual Studio Code:** editor de código para crear y modificar los archivos del proyecto.
- **Git:** herramienta para llevar el control de versiones del código.
- **GitHub:** plataforma para almacenar y compartir el proyecto.

##  Estructura del proyecto

```text
Chat-de-Musica/
│
├── main.py
├── musica.py
├── README.md
└── .gitignore
```

- **main.py:** archivo principal que inicia el programa y permite la interacción con el usuario.
- **musica.py:** contiene la lógica del chatbot y las respuestas relacionadas con la música.
- **README.md:** documento que explica el funcionamiento del proyecto.
- **.gitignore:** permite indicar qué archivos no deben subirse al repositorio de GitHub.

*La estructura puede variar según la organización final del proyecto.*

##  Requisitos

Para ejecutar el proyecto necesitas:

- Tener instalado Python 3.
- Contar con Visual Studio Code o algún editor de código.
- Tener los archivos del proyecto en una misma carpeta.

## Cómo ejecutar el programa

1. Abre la carpeta del proyecto en Visual Studio Code.
2. Abre la terminal integrada.
3. Verifica que Python esté instalado ejecutando:

   ```bash
   python --version
   ```

4. Ejecuta el archivo principal:

   ```bash
   python main.py
   ```

5. Escribe tus mensajes en la terminal para conversar con el chatbot.
6. Para finalizar la conversación, escribe `adiós` o `adios`, según lo configurado en el programa.

## Funcionamiento

El chatbot recibe los mensajes escritos por el usuario, analiza el texto ingresado y genera una respuesta de acuerdo con las condiciones programadas.

El funcionamiento general es el siguiente:

1. Se inicia el programa.
2. El chatbot se prepara para recibir mensajes.
3. El usuario escribe una pregunta o comentario.
4. El programa analiza el mensaje y selecciona una respuesta.
5. La conversación continúa hasta que el usuario decide salir.


Con este proyecto se practican los siguientes conceptos:

- Uso de variables y funciones.
- Creación y utilización de clases en Python.
- Entrada y salida de datos mediante la terminal.
- Condicionales y ciclos.
- Manipulación de cadenas de texto.
- Organización de un proyecto en varios archivos.
- Uso de Git y GitHub para administrar el código fuente.


En futuras versiones se podrían agregar recomendaciones de canciones, búsqueda por artista o género musical, registro de preferencias del usuario e integración con una API de música.
